# نظام إنشاء عقود الإيجار — أصول ريزيدنس

أداة ويب (Single Page Application) مخصصة لتسهيل وتسريع عملية إنشاء عقود الإيجار للمستأجرين في وحدات أصول ريزيدنس بشكل احترافي ومنظم.

## 🌟 المميزات الأساسية
- **واجهة ذكية وسريعة:** إدخال سلس لبيانات المستأجر، الوحدة، والتواريخ بضغطات بسيطة.
- **حسابات وتفقيط تلقائي:** حساب إجمالي مدد الإقامة (بالأيام أو الشهور) وتفقيط المبالغ المالية للغة العربية تلقائياً.
- **تصدير مرن:** 
  - طباعة العقد مباشرة بشكل رسمي.
  - الحفظ كملف PDF.
- **إدارة الصفقات:** إمكانية حفظ بيانات العقود محلياً (Local Storage) للرجوع إليها أو تعديلها في أي وقت.
